# Préparation - Site Web des Dates de Concerts

## Objectif
Créer un site web qui présente les différentes dates de concerts d'un groupe de musique camerounais : **"X-Maleya"**. Ce site permettra aux fans de consulter les dates, lieux, horaires et acheter des billets.

---

## Fonctionnalités Principales
1. **Liste des concerts** :
   - Affichage des dates, lieux et horaires des concerts.
   - Informations détaillées sur chaque événement (adresse, plan, invités spéciaux).
   
2. **Système de réservation** :
   - Intégration d’un lien vers une plateforme de billetterie (ex : Ticketmaster).
   - Gestion des disponibilités des places.

3. **Section "À propos"** :
   - Biographie du groupe "X-Maleya".
   - Photos et vidéos promotionnelles.

4. **Formulaire de contact** :
   - Permettre aux fans d’envoyer des questions ou commentaires.
   - Intégration des réseaux sociaux.

---

## Pages du Site
1. **Accueil** :
   - Message de bienvenue.
   - Aperçu des prochaines dates de concert.

2. **Tournée** :
   - Liste complète des concerts.
   - Filtrage par pays, ville ou date.

3. **À propos** :
   - Présentation du groupe.
   - Description du style musical et des membres.

4. **Contact** :
   - Formulaire de contact.
   - Liens vers les réseaux sociaux du groupe.

---

## Palette de Couleurs
Les couleurs utilisées pour le design du site web reflèteront une ambiance moderne et immersive, adaptée au style musical du groupe :
- **Couleur principale** : #1F2937 (Gris foncé - pour l'arrière-plan principal).
- **Couleur secondaire_1** : #F59E0B (Orange vif - pour les boutons et accents).
-**Couleur secondaire_2** : #825f26 (Pour les Header et Footer et aussi pour les boutons).
- **Couleur tertiaire** : #34D399 (Vert menthe - pour les liens et les détails).
- **Texte principal** : #FFFFFF (Blanc - pour le contenu principal).
- **Texte secondaire** : #D1D5DB (Gris clair - pour les sous-titres).

## Liens d'Inspiration
Voici quelques pages existantes pour vous inspirer dans la conception du site :
1. **Coldplay - Music of the Spheres Tour**  
   - URL : [https://www.coldplay.com/tour](https://www.coldplay.com/tour)  
   - Description : Présente les dates de tournée, les lieux, et un design moderne avec des animations dynamiques.

2. **Songkick - Concerts et Tournées**  
   - URL : [https://www.songkick.com/](ZS)  
   - Description : Plateforme pour suivre les artistes et découvrir leurs dates de tournée. Structure claire avec filtres pratiques.

3. **Ticketmaster - Concerts**  
   - URL : [https://www.ticketmaster.com/](https://www.ticketmaster.com/)  
   - Description : Billetterie en ligne avec affichage détaillé des concerts et achat rapide des billets.

4. **Ed Sheeran Official Website - Tour**  
   - URL : [https://www.edsheeran.com/tour](https://www.edsheeran.com/tour)  
   - Description : Site officiel avec des dates de concerts affichées dans un style épuré et accessible.

5. **Bandsintown - Trouver des concerts**  
   - URL : [https://www.bandsintown.com/](https://www.bandsintown.com/)  
   - Description : Plateforme pour découvrir des événements live, avec un design interactif et axé sur l'expérience utilisateur.
